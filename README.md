# nika-demo-mcp

Servidor MCP de demostracion del ecosistema NIKA: muestra como se declara un servidor con manifiesto de herramientas, nivel y permisos, y como se separan el servidor y los manejadores.

## Contenido
- server.py: arranque del servidor MCP.
- handlers.py: implementacion de las herramientas.
- manifest.json: nombre, version, nivel, permisos y herramientas.

## Requisitos
- Python 3.11.
